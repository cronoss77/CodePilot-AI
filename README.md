# CodePilot AI

CodePilot AI is an open-source Python developer tool designed to help programmers analyze source code, identify common code-quality issues, and automatically generate basic documentation.

The project is focused on making code analysis simple and accessible, especially for students, beginner developers, and open-source contributors.

> AI-assisted features are planned for future releases.

## Features

- Python source code analysis
- Syntax error detection
- Function structure analysis
- Detection of overly long functions
- Automatic function documentation generation
- Simple command-line interface
- Automated tests with pytest
- Open-source and community-driven
